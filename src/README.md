# Mergington High School Activities

A website application that allows students to view extracurricular activities and teachers to manage student registrations.

## Features

- View all available extracurricular activities with details, schedules, and current participants
- Filter activities by category (Sports, Arts, Academic, Community, Technology)
- Filter activities by day of the week
- Filter activities by time (Before School, After School, Weekend)
- Search activities by name, description, or schedule
- Visual capacity indicators showing enrollment status for each activity
- Teacher authentication system for managing student registrations
- Teachers can register students for activities
- Teachers can unregister students from activities
